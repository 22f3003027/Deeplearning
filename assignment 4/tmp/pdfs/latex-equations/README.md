# Group 32 LaTeX report

Main file: `Group32_Assignment4_report.tex`. Figures are local; no external files or Python are needed to compile.

Run twice from this directory:

```sh
pdflatex -interaction=nonstopmode -halt-on-error Group32_Assignment4_report.tex
pdflatex -interaction=nonstopmode -halt-on-error Group32_Assignment4_report.tex
```

For Overleaf, upload this project ZIP and set the main document to the `.tex` file. Use pdfLaTeX.
All table values are generated from measured experiment results. You can edit the LaTeX normally.
